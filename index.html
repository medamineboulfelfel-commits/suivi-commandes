Règle de calcul : vous saisissez la Consommation totale et le Déchet total par matière. La consommation est répartie automatiquement selon FIFO entre les lots internes. Aucune clôture manuelle n’est nécessaire.

Réception des matières

Saisie manuelle
Ajoutez une ligne par matière et par Lot interne reçu. Si une matière arrive avec plusieurs lots internes, ajoutez plusieurs lignes pour cette matière. L'unité peut être différente pour chaque matière.

Sauvegarde et restauration

Les données sont enregistrées localement dans ce navigateur. Pour éviter toute perte, exportez régulièrement une sauvegarde JSON. La sauvegarde peut être importée sur ce même appareil ou un autre navigateur.

Important : l'enregistrement local ne synchronise pas automatiquement les données entre plusieurs appareils et peut être effacé si les données du navigateur sont supprimées. Gardez une sauvegarde exportée.
